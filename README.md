# 🏔️ Leh–Nubra–Pangong–Manali Road Trip Expedition 2026

An elegant, high-fidelity, responsive static web application designed to plan, track, and manage your upcoming adventure road trip from July 3 to July 11, 2026. 

This dashboard is fully optimized for mobile devices and laptops, making it the perfect offline-ready companion to access while on the road.

---

## 🌟 Key Features

1. **Interactive Route Timeline**: Navigate day-by-day (Day 1 to 9) to view exact route segments, start times, travel distances, estimated driving times, altitude peaks, road ratings, and must-see sightseeing stops with direct Google Maps routes.
2. **Detailed Sightseeing Hyperlinks**: Direct Google Maps lookup integration for every scenic pass, temple, monastery, and landmark along the way.
3. **Static Gear & Packing Guide**: Complete checklists split into 5 crucial categories (Documents, Clothing, Electronics, Health/Medical, and Vehicle) presented in clean, readable lists.
4. **Altitude & Elevation Profile**: Interactive SVG altitude profile chart highlighting elevation levels at each destination with click tooltips and active altitude warnings.
5. **Logistics & Stays**: Strategic lists detailing critical fuel stations, night stays status, and direct link to LAHDC Inner Line Permit portal.
